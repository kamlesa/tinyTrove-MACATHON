MAC Hackathon - Macathon 2026

## Expo React Native App

A minimal React + Expo Go starter app is scaffolded in this repository.

### Run the app

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start Expo:
   ```bash
   npm run start
   ```
3. Open in Expo Go on your device or emulator.


### Database SetUp

1. Install supabase:
   ``` bash
   npm install @supabase/supabase-js
   ```
2. Install dependencies
   ```bash
   npx expo install @supabase/supabase-js @react-native-async-storage/async-storage expo-secure-store expo-splash-screen
   ```

   If error occurs try running:

   ```
   npm install expo
   ``` and then run the above dependency again
